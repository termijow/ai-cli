# Procedure: Real-Time LLM API Savings Tracking

## Overview
This skill captures the approach for tracking LLM API usage costs in real-time during `ai` command execution, using token counts from the LLM response and maintaining a running total in `$.ai_cli_savings`.

## Key Components

### 1. Token Extraction from LLM Response
- After calling the LLM API, extract token counts from the response JSON:
  - `prompt_tokens`: Tokens sent to the LLM
  - `completion_tokens`: Tokens generated by the LLM

### 2. Cost Calculation Using Pricing Rates
- **Input tokens (user prompts)**: $0.0000050 per token
- **Output tokens (LLM responses)**: $0.0000100 per token
- Formula: `total_savings = (prompt_tokens * 0.0000050) + (completion_tokens * 0.0000100)`

### 3. Savings File Management
- **File location**: `$.ai_cli_savings`
- **Operation**: Read current total, add new session savings, write back with 2 decimal places
- **Missing file handling**: Initialize with "0" if file doesn't exist

### 4. Display to User
- Show savings amount for the current call
- Display cumulative total savings
- Format: `💸 Savings on this query: $X.XXXX USD | Cumulative total: $Y.YYYY USD`

### 5. History Logging (Optional)
- Append query entries to JSONL file (`.ai_cli_history/queries.jsonl`)
- Fields: timestamp, query_type, prompt_tokens, completion_tokens, savings, total_savings
- Rotation policy: Keep only last 20 entries

## Tooling

- **jq**: Extract token counts from LLM API response JSON
- **awk**: Floating-point arithmetic for cost calculations
- **bash**: File I/O, conditionals, and string manipulation

## Configuration Points

- **Token pricing**: $0.000005 per prompt token, $0.000010 per completion token
- **Savings file**: `$.ai_cli_savings`
- **History limit**: 20 entries
- **History directory**: `$.ai_cli_history/`

## Dependencies

- Bash 4+ (for `[[ ]]` syntax and `$((...))` arithmetic)
- jq (for JSON parsing)
- awk (for floating-point calculations)

## Error Handling

- Handle missing savings file (initialize with 0)
- Handle missing history directory (create if needed)
- Handle empty token values (treat as 0)
- Use `2>/dev/null` to suppress jq errors
